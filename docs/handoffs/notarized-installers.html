Behavior¶ ↑

New releases use a cask without quarantine-removal preflight actions. Its installer directly executes the signed Go controller with the existing private payload. Stable CLI wrappers, non-root installation, independent queue retention and non-destructive uninstall behavior remain in place.

For an unchanged published build, the refresh helper retains the exact historical cask after validating it against its original bounded public asset. It does not execute that historical Ruby. The next numbered release adopts the new template. Keep the current paired Casks manifest and Ruby file throughout this transition; never remove them to force a template change.
